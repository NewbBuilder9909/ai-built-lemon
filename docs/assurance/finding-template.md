# Restricted security finding record

Copy into the approved restricted tracking system. Keep exploit details,
credentials and customer information out of public issues and this repository.

| Field | Value |
|---|---|
| Finding ID / related readiness control IDs | OPEN |
| Title / source / discovered UTC | OPEN |
| Affected commit, artifact, config revision and asset | OPEN |
| Affected tenant/role/data and attack prerequisites | OPEN |
| Severity, CVSS version/vector if applicable, business impact | OPEN |
| Reproduction and evidence | Restricted link + digest; redact sensitive data |
| Named accountable owner / due date | OPEN |
| Immediate containment / long-term remedy | OPEN |
| State | Open / triaged / fixing / awaiting retest / closed / accepted risk |
| Fix revision and relevant regression checks | OPEN |
| Independent retester, UTC, environment and result | OPEN |
| Residual risk, compensating controls and monitoring | OPEN |
| Acceptance authority, rationale, date and expiry | OPEN; expiry requires reassessment |
| Customer/contract notification decision and owner | OPEN |

Closure requires fixed-version evidence and retest. Risk acceptance is a distinct
state, not a successful test. Reopen if retest fails or an acceptance expires.
